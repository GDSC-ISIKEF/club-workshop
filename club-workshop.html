The first commit cycle

Five commands. One loop.

1git add <file>Stage the change
2git statusCheck the staged state
3git commit -m "Message"Save a snapshot locally
4git log --onelineSee the history
5git pushSend it to GitHub
What is a branch?

An independent line of work.

main is the version everyone trusts. Feature branches let you change things without touching it.

git switch main
git pull
git branch

Merge conflicts

Same lines. Two branches. One human decision.

Git can't pick a winner, so it asks you.

GitHub warns on the PR: “This branch has conflicts that must be resolved.”
git switch main
git pull
git checkout -b conflict-<username>

Resolving a conflict

Edit. Add. Commit. Push.

1
Edit the fileWrite the correct final text and delete all three marker lines.
2
git add <file>Then git commit to record the resolution.
3
git pushThe PR updates and the warning disappears.

Fetch downloads and looks.
Pull downloads and merges.

git fetchDownloads new commits and updates origin/main. Changes nothing else.
git pullFetch, then merge into your current branch.
