# club-workshop

hands-on repo for the **git & gitHub** session, run by **GDSC ISIKEF** and **Mosaïque Clu

Everyone here practices the same workflow you'll use on real projects: branch, commit, push, open a pull request, review, merge!

## before you start test

- install [git](https://git-scm.com/downloads)
- create a [github account](https://github.com/signup) and confirm you can log in
- accept the invitation to this repo (check your email or gitHub notifications)

## guick start

```bash
git clone https://github.com/<org-name>/club-workshop.git
cd club-workshop
git switch -c add-<your-name>
```

## how to contribute

1. pick an open issue and comment that you're taking it
2. create a branch named `add-<your-name>` or `fix-<short-description>`
3. make your change
4. commit with a short message, for example `add youcef to participants`
5. push the branch and open a pull request. write `closes #<issue-number>` in the description
6. ask a partner to review your PR, and leave at least one comment on theirs

## folder structure

- `participants/`: add your own file here, named `<your-name>.md`, with one line about yourself
- `README.md`: this file

## rules for this repo

- don't push directly to `main`. **ALWAYS** use a branch and a PR
- keep changes small. one issue per PR
- be kind in reviews. point out problems and suggest fixes

## need help?

ask a helper in the room, or raise your hand. nobody gets left behind!!!
